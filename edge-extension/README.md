当前扩展 **0.11.0** / 服务 **0.14.0**。网页识别和发送作为主要接入方式，小红书内置适配保留，其他网页可导入 DOM 适配文件。日常无需填写每位顾客的信息。

升级、渠道规则设置、本地演示和适配说明见 [通用网页客服](../docs/WEB-CHANNELS.md)。更新时重启后端、重新加载扩展并刷新聊天页。新页面先点“仅打开面板，先检测页面”。

网页访问权限由浏览器针对选定站点授予，不默认读取所有网站。每个适配器使用独立专用标签页，故障、暂停和恢复意图分别保存；小红书旧的待办、防重和草稿保留。淘宝等网页仍需按实际聊天结构制作适配，不属于已经实测的内置平台。

# 知答 · Edge 智能客服

以下为历史版本记录。

0.8.10 无法处理时只对外发送“不好意思，请稍等”，同一待办不重复发送；原因、通知和人工处理入口继续保留在后台。服务端 0.8.6 与网站客服规则同步改为简短自然，不主动介绍智能助手、知识库或接口；仅在被明确询问身份时如实简短说明自动回复。更新后重新加载扩展并刷新聊天页。

0.8.9 默认改为 B「暖纸墨棕」：暖白背景、深棕文字、深绿主按钮，保留绿／红／黄色状态。首次升级到本配色会将旧主题选择切到日间；之后手动选择夜间或自动仍会保存。主题菜单的日间选项标为“日间 · 暖纸墨棕 B”。仅更新扩展，无需重启后端。

0.8.8 增加面板顶部“界面主题”：日间（白底深字）、夜间（C2 墨黑冰蓝）、自动（默认）。自动优先读取聊天页面实际背景深浅，背景无法判断时跟随系统深色设置，并响应页面及系统变化。选择保存在本机，切换不停止接待、不重建表单。夜间常用按钮为冰蓝色、编辑框白底黑字；日间低频说明用浅灰底。两种配色均保留绿色正常、红色报错、黄色等待。仅更新扩展，后端无需重启。

0.8.7 状态提示按语义着色：正常运行绿色，错误红色，暂停与等待黄色。平台限制、扩展失效、启动失败等错误不会被普通健康状态刷新成暂停色；悬浮球同步显示错误状态。后端无需重启。

0.8.6 在右上角缩小与关闭按钮之间增加“放大编辑窗口／还原窗口”。放大到最多 960px 宽、接近屏幕高度，保持编辑内容；再次点击恢复原大小和位置。放大后收成悬浮球，再展开仍为大窗口。后端仍为 0.8.4，无需重启；更新前先保存正在编辑的内容，再重新加载扩展并刷新聊天页。

0.8.5 遇到平台限制后停止自动恢复与页面检查，禁止重复启动；扩展失效时明确提示刷新。后端继续使用 0.8.4，无需重启。平台已经显示的限制仍需停用扩展，按平台提示处理；不能通过本次修正保证解除。详见 [故障处理](TROUBLESHOOTING.md)。

0.8.4 配合网站客服知识扩充，修正安全提醒误拦截。服务端同为 0.8.4；更新时重启本地服务、重新加载扩展并刷新聊天页。知识查看与修改见 [使用说明](../knowledge-packs/使用与修改说明.md)。

0.8.3 使用高对比工作界面：正文 16px、辅助文字 15px、运行提示 18px；保留白瓷悬浮球。工作台与扩展弹窗同步改善文字、边框和小窗口排版。

扩展统一使用智能客服面板，旧的页面校准监听和弹窗手动草稿已删除。面板内仍提供只检测、生成草稿、单条发送验证及日常自动接待。

## 更新与使用

1. 运行本地服务 `start.cmd`，打开工作台发布业务知识。
2. 在 `edge://extensions` 加载本目录，已有安装点击“重新加载”，版本应为 0.11.0；刷新小红书聊天页。更新前先保存正在修改的内容。若平台已经限制访问，先按故障处理说明停用扩展，确认手动聊天正常后再启用。
3. 首次在扩展中填写 `data/edge-bridge-token.txt` 的本地连接令牌。它不是模型密钥，保存在当前浏览器本机。
4. 选择已发布业务，点击“检查并开始接待”。客服面板可拖动、收成悬浮球；人工待办从独立窗口处理。
5. 需要只检测或生成草稿时，在客服面板的“检测、草稿和单条验证”中选择模式。

本次更新需要重启后端加载新检索与接待逻辑；工作台按 Ctrl+F5 刷新。新增通用知识由安装脚本发布，待补资料不参与回答。业务、人工待办和防重记录保留。

完整功能、数据保留、权限和验收步骤见 [实施与验收说明](../docs/releases/IMPLEMENTATION-0.8.0.md)。本扩展通过网页操作接待，不是平台官方客服接口；平台限制出现时停止并按页面提示处理。
