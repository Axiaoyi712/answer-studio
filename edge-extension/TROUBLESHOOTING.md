# 平台限制与扩展失效

## 小红书显示“限制访问／浏览器异常”

这是平台页面给出的提示，不是模型回答错误。单凭提示不能确定具体触发原因，也不能据此认定账号已被封禁。

1. 打开 `edge://extensions`，先关闭“知答”开关。
2. 关闭原小红书标签页，按平台提示重启 Edge，再手动打开消息页。
3. 保持扩展关闭，确认能否正常打开和手动聊天。如果仍受限，通过页面“问题反馈”处理，不连续刷新或尝试发送。
4. 手动聊天恢复正常后，如需再次使用，重新加载扩展 0.8.5，再启用，刷新聊天页并手动启动。若启用后限制再次出现，立即停用；当前网页自动接待方式可能不适用于该账号或环境，需要重新评估渠道。

0.8.5 在收到明确的平台限制结果时清除自动恢复意图，并停止旧面板的检测定时器和页面观察，禁用启动按钮；不会自动关闭平台弹窗、刷新页面、重新登录或继续发送。知识库与待办保留。全局平台故障与单个客户需要人工是不同情况。

## Extension context invalidated

通常发生在更新、重新加载或停用扩展后，旧标签页中的脚本已失效。刷新聊天页再打开助手即可。0.8.5 会停止失效的恢复轮询；客服面板显示“刷新聊天页”按钮，不再只显示英文错误。

重新加载扩展不会替已经打开的标签页更新旧脚本，所以更新后必须刷新页面。本次仅更新扩展，无需重启本地问答服务或重新发布知识。
