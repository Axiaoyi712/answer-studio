# 客服知识补全清单

按 Bitext 27 个公开意图标签整理的中文核对表。标签来源与 CDLA Sharing 1.0 许可见 [catalog.json](catalog.json)。© Bitext Innovations, 2023；中文示例与资料要求是本项目新增映射说明，不是原始客户对话或经营事实。本适配清单保留相同数据许可和署名。

适用于你的业务才补充，不适用的明确写“不提供”。可在现有对话建库窗口按这些主题交谈，整理出的事实仍需你审核发布。

| 主题 / 原始意图 | 新编中文问法 | 应确认的资料或能力 |
| --- | --- | --- |
| 下单 place_order | 怎么买？ | 商品规格、数量、允许的购买入口；不虚构已下单。 |
| 取消 cancel_order | 帮我取消这单。 | 取消条件、订单核实、真实执行权限。 |
| 修改 change_order | 想换个型号。 | 可修改阶段、差价及处理流程。 |
| 改地址 change_shipping_address | 下单地址填错了。 | 查询资格、发货阶段、真实修改流程。 |
| 取消费用 check_cancellation_fee | 取消扣钱吗？ | 费用、条件、生效时间。 |
| 查发票 check_invoice | 发票开好了吗？ | 真实进度来源和查询资格。 |
| 支付方式 check_payment_methods | 怎么付款？ | 实际渠道与限制。 |
| 退款政策 check_refund_policy | 买前想问能不能退。 | 条件、例外、时限、费用；区分政策咨询与实际申请。 |
| 投诉 complaint | 我要投诉。 | 负责人、流程、时限；不擅自承诺赔偿。 |
| 联系客服 contact_customer_service | 出问题去哪问？ | 真实支持入口与服务时间。 |
| 请求人工 contact_human_agent | 找个人看看。 | 后台待办、负责人和接管恢复；客户侧简短等待。 |
| 注册 create_account | 怎么注册你们网站？ | 本站实际流程，不推断第三方账号资格。 |
| 注销 delete_account | 想注销账户。 | 是否提供、身份验证及执行权限。 |
| 配送方式 delivery_options | 发什么快递？ | 地区、运费、快递、禁限寄条件。 |
| 配送时间 delivery_period | 什么时候到？ | 发货、预售例外、预计送达分别说明。 |
| 修改账户 edit_account | 资料怎么改？ | 可修改项、正式流程；不收登录凭证。 |
| 申请发票 get_invoice | 能开电子发票吗？ | 类型、条件与申请方式。 |
| 退款申请 get_refund | 我付款了，要退款。 | 真实售后与核实流程；无权限不宣称完成。 |
| 通知订阅 newsletter_subscription | 上新能告诉我吗？ | 是否提供、自愿订阅和取消。 |
| 支付异常 payment_issue | 扣款没订单。 | 订单支付核实；截图不能单独证明付款成功。 |
| 找回密码 recover_password | 忘记密码了。 | 正式找回入口；不收密码或验证码。 |
| 注册异常 registration_problems | 注册一直失败。 | 确认过的错误及排查步骤。 |
| 评价 review | 哪里评价？ | 实际位置；不引导虚假评价。 |
| 设置地址 set_up_shipping_address | 地址在哪填？ | 本站真实入口和步骤。 |
| 切换账户 switch_account | 怎么换账户？ | 支持的切换、退出方式。 |
| 订单查询 track_order | 我的订单到哪了？ | 真实数据与授权；不从知识库猜进度。 |
| 退款查询 track_refund | 退款到账了吗？ | 真实状态、确认的时限与异常流程。 |

此外需单独补充商品目录、别名、规格、颜色、计价单位、阶梯价格、库存来源、有效期和适用条件；通用意图数据不能替你确认这些事实。
